# แผนลดไขมัน 18 วัน

เว็บแอปติดตามแผนอาหาร เวท เดินชัน และน้ำหนัก ใช้งานบนมือถือได้ ติดตั้งลงหน้าจอหลักได้ และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ขึ้น GitHub Pages (ทำจากมือถือได้ทั้งหมด)
1. เข้า github.com → ปุ่ม **+** → **New repository** ตั้งชื่อ เช่น `fatloss-18day` เลือก **Public** → Create
2. กด **uploading an existing file** → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `manifest.webmanifest`, `sw.js`, โฟลเดอร์ `icons`) → Commit
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/fatloss-18day/`

## ติดตั้งลงมือถือ
- iPhone: เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- Android: เปิดใน Chrome → เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงหน้าจอหลัก**

## หมายเหตุ
- ข้อมูลที่ติ๊ก/บันทึกเก็บในเครื่องนั้นๆ (localStorage) ไม่ซิงค์ข้ามเครื่อง และจะหายถ้าล้างข้อมูลเบราว์เซอร์
- ถ้าแก้ไฟล์แล้วหน้าเว็บยังเป็นของเก่า ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `fl18-v2`)
